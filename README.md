# Life Designer

> 不是帮你想清楚，是陪你走出来。

把斯坦福连续 11 年最受欢迎的课——Life Design Lab——变成一个 AI 人生设计教练。跟它聊 20-60 分钟，陪你走完四个阶段，最后生成一份 8000+ 字的《个人人生设计蓝图》。

**不是诊断书，不是鸡汤，是一封真正懂你的朋友写给你的长信。**

---

## 四阶段对话

```
你在这里     →   给健康/工作/娱乐/爱打分，找到真正失衡的地方
你的指南针   →   你的工作观和人生观在指向同一个方向吗？
寻路         →   那些让你忘记时间的时刻，藏着你的答案
多种可能     →   设计三个完全不同的五年人生版本——三个都是 A 计划
```

聊完你能回答三个问题：**我的真问题是什么？我有哪三条路？明天就能做什么？**

---

## ✉ 时间胶囊

对话结束的那一刻，AI 会用「今天的你」的口吻，写两封信——一封给 30 天后的你，一封给 90 天后的你。

不是 AI 写的鸡汤——是你自己说过的话、做过的选择、流过的能量，被封存进一个带日期锁的网页里。没到时间打不开，到时间封印自动解开。

> 「我像个跑步机——跑得很快，但原地不动。」
> 
> 你还记得那个下午吗？你终于坐下来，认真地问自己：我到底想要什么样的生活？……

同时生成一个 `.ics` 日历文件——双击导入你的日历，30/90 天后它会自动提醒你回来读信。

## 为什么不一样

网上有很多「人生设计 Prompt」，大部分的问题是——**AI 说话太像 AI 了。**

这个 Skill 写了 50+ 条「永远不要这样说」的表达规则，确保对话温暖、松弛、偶尔一针见血：

| ❌ AI 的通病 | ✅ 它会说的 |
|---|---|
| 「我理解你的感受」 | 「这句话我记住了」 |
| 「根据分析，你的核心问题是...」 | 「我觉得真正卡住你的可能不是你以为的那件事」 |
| 「加油你可以的！」 | 「你已经有方向了——只是还没允许自己看见」 |

每个对话阶段都有好/坏回应的逐字对比，详见 [SKILL.md](./SKILL.md)。

## Life Design Studio Web（阶段 1.2 · 本地 Codex 完整体验）

仓库正在增加一个移动端优先、可中断恢复的 Web 体验。当前版本已经覆盖四阶段、八份标准素材，并把第一阶段升级成引导式教练：先给选择和例子，再陪用户聚焦困扰、回忆真实时刻、识别感受、区分现实边界，最后确认一份可编辑的小结。

如果这台电脑已经安装并登录 Codex，可以启用本地完整体验：每个关键回答保存后，Codex 会生成一段忠实承接、一个可能的洞察和一个具体追问；完成四阶段后，会生成可保存、刷新恢复、下载 Markdown 和打印为 PDF 的《个人人生设计蓝图》。

```bash
pnpm install
LIFE_DESIGN_LOCAL_CODEX=1 pnpm --filter @life-design/web dev --port 3010 --hostname localhost
```

打开 <http://localhost:3010>。第一阶段每次只处理一个小问题：

1. 了解过程、时间和本地隐私边界；
2. 用带语义锚点的评分看健康、工作、娱乐和爱；
3. 从较低分领域中选择这次真正想谈的重点；
4. 从具体困扰卡开始，把问题改成自己的话；
5. 回到一个真实事件并选择当时的感受；
6. 区分能改变、能影响和暂时只能接受的部分；
7. 修改并确认系统的复述草稿。

后续继续完成工作观、人生观、能量地图、三套五年方案和低成本原型。每个微步骤都会先写入本机 IndexedDB，再调用模型；返回不会清空答案，关闭页面后重新打开会回到准确断点。模型失败时可以重试或跳过，不能反过来阻塞用户拿回自己的素材。八份素材全部齐全后才允许生成最终蓝图。

### 本地模型与隐私边界

- Web 前端不会读取或保存 Codex API Key；服务端使用这台电脑当前已经登录的 Codex。
- 每次调用使用临时会话、只读沙箱和结构化输出，不加载用户 MCP、规则或项目文件。
- 用户本次人生设计检查点会发送给 OpenAI 以生成回应和蓝图；它不是离线模型。
- 回答、AI 回应和蓝图默认保存在浏览器 IndexedDB。当前适配器只用于本机产品验收，不是公开部署方案。
- 未设置 `LIFE_DESIGN_LOCAL_CODEX=1` 时，页面仍可保存并完成结构化本地流程；模型节点可以选择跳过。

验证命令：

```bash
pnpm test
pnpm typecheck
pnpm test:e2e
pnpm --filter @life-design/web build
```

本地 Codex 适配器用于先验证完整产品体验。公开开源版本后续仍会保留确定性流程，并增加可替换的 BYOK Provider；托管体验则使用独立服务端代理、额度和隐私边界，不能直接把本地 CLI 方案部署到公网。
